<ktjs-features section-title="What you get" tinted>

<ktjs-feature icon="lucide:table" title="The community surface, all of it">1882 declarations reached from the upstream `main.d.ts` — grid options, column definitions, the GridApi, events, renderers, filters, the Theming API and the locale tables.</ktjs-feature>

<ktjs-feature icon="lucide:shield-check" title="Checked by the compiler">Every option, callback and literal is an `external` declaration, so a misspelled property or a wrong branch of a string union fails `./gradlew build` instead of failing in the browser.</ktjs-feature>

<ktjs-feature icon="lucide:wrench" title="Generated, not transcribed">The declarations are emitted from the published `.d.ts` files; upgrading AG Grid means bumping one npm version and re-running the generator.</ktjs-feature>

<ktjs-feature icon="lucide:scale" title="Open source only">`ag-grid-community` and `@ag-grid-community/locale`, both MIT. Nothing from the commercially licensed Enterprise packages is stubbed, referenced or required.</ktjs-feature>

<ktjs-feature icon="lucide:languages" title="Bilingual, from the data">`AG_GRID_LOCALE_EN_US` and `AG_GRID_LOCALE_ZH_CN` are plain values, so a language switch is one option assignment — the demo does exactly that.</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="Tested against the real grid">The wrapper's browser tests register the community module and create a grid in Chromium; the demo has its own Playwright suite.</ktjs-feature>

</ktjs-features>
