<ktjs-features section-title="你会得到什么" tinted>

<ktjs-feature icon="lucide:table" title="完整的社区版 API">从上游 `main.d.ts` 可达的 1882 个声明——网格选项、列定义、GridApi、事件、渲染器、筛选器、Theming API 以及 locale 文案表。</ktjs-feature>

<ktjs-feature icon="lucide:shield-check" title="编译器检查">每个选项、回调和字面量都是 `external` 声明，属性拼错或字符串联合选错分支，会让 `./gradlew build` 失败，而不是在浏览器里失败。</ktjs-feature>

<ktjs-feature icon="lucide:wrench" title="生成而非抄写">声明由发布的 `.d.ts` 发射而来；升级 AG Grid 只需改一个 npm 版本号再重跑生成器。</ktjs-feature>

<ktjs-feature icon="lucide:scale" title="只做开源部分">`ag-grid-community` 与 `@ag-grid-community/locale`，都是 MIT。商业授权的 Enterprise 包一个都没有打桩、引用或依赖。</ktjs-feature>

<ktjs-feature icon="lucide:languages" title="双语来自数据">`AG_GRID_LOCALE_EN_US` 与 `AG_GRID_LOCALE_ZH_CN` 就是普通值，切换语言等于赋一个选项——示例页正是这么做的。</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="用真实表格验证">封装的浏览器测试在 Chromium 里注册社区模块并创建表格；示例页另有自己的 Playwright 套件。</ktjs-feature>

</ktjs-features>
